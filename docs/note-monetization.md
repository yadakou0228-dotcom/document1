# note収益化戦略:Claude Code活用プラン

企画:「消防士→青年海外協力隊」ドキュメンタリーの**noteでのテキスト展開と収益化**、および
Claude Codeを使った記事制作・運用の進め方をまとめる。

YouTubeチャンネル([初期構成・投稿プラン](posting-plan.md))と連動させ、
**動画=無料で共感を集める入口、note=深い情報を届けて収益化する出口**という役割分担を基本とする。

## 0. 最重要の前提:収益化を開始できる時期

- 消防士は地方公務員であり、**在職中の営利目的の副業は地方公務員法(営利企業への従事等の制限)に
  抵触するおそれがある**。noteの有料販売・サポート受け取りも収益に該当しうる。
- したがって本プランでは、**在職中(〜2027/3/31)は無料記事のみでファンと記事資産を蓄積し、
  収益化(有料化)は退職後(2027/4/1以降)に開始する**ことを基本方針とする。
- 在職中に収益化を前倒ししたい場合は、所属の服務規程の確認・許可申請が必須。自己判断で始めない。
- 退職後もJICA・協力隊の情報発信ガイドライン(SNS規程等)の確認は引き続き必要
  ([市場分析](market-analysis.md)のリスク項目参照)。

## 1. noteの収益化手段と本企画への適合度

| 手段 | 仕組み | 本企画への適合度 |
|---|---|---|
| 有料記事(単発) | 記事ごとに100〜50,000円で販売。途中まで無料公開し続きを有料にできる | ◎ 「協力隊の選考対策」「応募書類の実例」など単発で価値が完結するノウハウ記事に最適 |
| 有料マガジン | 複数の有料記事をまとめ買い形式で販売 | ○ 選考対策シリーズなど記事が溜まった段階でセット化 |
| 定期購読マガジン(月額) | 月額制で継続課金。開設には審査あり | ○ 派遣後の「現地生活の裏側」連載に向く。フェーズ3で検討 |
| メンバーシップ | 月額制コミュニティ。限定記事・掲示板 | ○ 「転職・協力隊を目指す人のコミュニティ」として育てば有力。ファンが付いてから |
| サポート(投げ銭) | 読者からの任意の支援 | △ 設定しておくだけでよい(在職中はオフにする) |

**推奨の順番**: 有料記事(単発)→ 有料マガジン → 定期購読 or メンバーシップ。
最初から月額制を狙わず、単発記事で「売れるテーマ」を検証してから積み上げる。

## 2. コンテンツ戦略:無料と有料の切り分け

### 無料記事(集客・信頼づくり)

YouTubeと同じ「ストーリー・共感」の軸。動画を観ない層への入口にもなる。

- 退職までのカウントダウン日記(動画の内容をテキスト化+動画で話せなかった補足)
- 協力隊制度の基礎解説(検索流入を狙う)
- 心境・葛藤系のエッセイ(noteはエッセイとの相性が良い)

### 有料記事(収益の柱/退職後に販売開始)

「読者が自分の行動に使える具体情報」に絞る。共感ではなく**実用性**で課金してもらう。

| テーマ案 | 想定読者 | 価格帯の目安 |
|---|---|---|
| JICA海外協力隊 選考対策の全記録(応募書類の書き方・面接で聞かれたこと) | 協力隊応募を考える人 | 500〜1,500円 |
| 公務員を辞めるまでにやった手続き・お金の全リスト | 公務員からの転職検討者 | 300〜1,000円 |
| 派遣前訓練のリアル(持ち物・語学・生活) | 合格者・応募検討者 | 300〜800円 |
| 現地生活の家計簿・住環境の実際 | 海外移住検討者 | 300〜800円 |

ポイント:**冒頭〜7割を無料公開し、核心部分(実例・具体的数字)を有料ラインの下に置く**のがnoteの定石。

### YouTubeとの連動

- 各動画の概要欄・固定コメントにnoteリンクを置く(「詳しいノウハウはnoteに」)
- note記事末尾に動画リンクを置き、相互送客する
- EP2(協力隊制度解説)・EP4(選考試験)・EP9(持ち物)は特にnote記事化との相性が良い

## 3. フェーズ別プラン

| フェーズ | 期間 | noteでやること |
|---|---|---|
| フェーズ0:助走期 | 今〜2026/12 | **フォロワー獲得に集中**([noteフォロワー獲得戦略](note-follower-growth.md)参照)。アカウント設計と記事の書き溜めをリポジトリで開始 |
| フェーズ1:資産構築期 | 2026/12/21〜2027/3/31 | **無料記事のみ**を週1本、YouTube投稿と同日に公開。フォロワーとスキを蓄積 |
| フェーズ2:収益化開始 | 2027/4/1〜派遣まで | 有料記事の販売開始(選考対策・退職手続き系)。反応を見て有料マガジン化 |
| フェーズ3:継続収益期 | 派遣後 | 定期購読マガジン or メンバーシップの開設を検討。現地からの連載を軸に |

## 4. Claude Codeを使った記事制作・運用ワークフロー

記事をこのリポジトリでGit管理し、制作の各工程でClaude Codeを使う。

### リポジトリ構成(追加案)

```
note/
├── ideas.md          # ネタ帳(思いつきをここに追記)
├── schedule.md       # 公開カレンダー(YouTube投稿プランと連動)
├── drafts/           # 下書き(1記事1ファイル)
└── published/        # 公開済み記事のアーカイブ(公開日をファイル名に含める)
```

### 工程ごとのClaude Codeの使い方

| 工程 | Claude Codeへの依頼例 |
|---|---|
| 企画 | 「ideas.mdのネタを、無料/有料・想定読者・検索キーワードで整理して」 |
| 下書き | 「EP4の台本(docs/templates準拠)をもとに、note記事の下書きをテンプレートに沿って作って」 |
| リパーパス | 「この動画台本を、noteのエッセイ調に書き直して。動画にない補足を入れる箇所に TODO を入れて」 |
| 有料ライン設計 | 「この記事の無料部分と有料部分の切れ目を提案して。無料部分だけで価値が伝わるかも指摘して」 |
| 校正 | 「公開前チェックリストに沿って、個人・所属が特定される記述がないか確認して」 |
| 分析 | 「published/の記事一覧に、スキ数・販売数を記録した表を作って。伸びた記事の共通点を分析して」 |

### 運用ルール

1. 記事は必ず`drafts/`で作成し、[note記事テンプレート](templates/note-article-template.md)に沿って書く
2. 公開前に[チェックリスト](checklists.md)の個人情報・所属特定リスク項目を必ず確認する
   (テキストは動画より検索に残りやすく、特定リスクが高い)
3. 公開したら`published/`へ移動し、公開日・無料/有料・価格をファイル冒頭に記録する
4. 週次でスキ数・フォロワー数・(退職後は)販売数を`schedule.md`に記録し、Claude Codeで振り返る

## 5. KPIの目安

| 時期 | 指標 |
|---|---|
| フェーズ1終了時(2027/3) | フォロワー300人・無料記事15本(週1×15週) |
| フェーズ2(退職後3ヶ月) | 有料記事3〜5本公開・初売上の発生・売れ筋テーマの特定 |
| フェーズ3(派遣後半年) | 月額商品(定期購読 or メンバーシップ)開設の可否判断 |

数字は仮置き。実績が出たら実態に合わせて更新する。

## 6. リスク・注意点(note固有)

- **在職中の収益化は行わない**(第0章)。サポート機能もオフにしておく
- 有料記事の返金対応・低評価リスクに備え、**販売ページ(無料部分)で内容を正確に予告**する
- 協力隊の選考情報は年度で変わるため、有料記事には「いつ時点の情報か」を明記する
- noteの規約・手数料(プラットフォーム利用料+決済手数料)を把握した上で価格設定する
