## 前回分析（8月16日）からの修正点

8月16日版の最有力シナリオは「2026年11月に $51,000 で底入れ」と置いた。
実際の11月13日時点は $71,300 で、**+40%の上方乖離**。

### 1. 機関投資家の押し目買いの厚みを過小評価していた

6月の $58,500 は実質的な底として機能した。8〜9月にスポットETFへ合計約61億ドル
（8月 +35億、9月 +26億）が流入し、価格は10月6日の $86,000 まで **+47%** 急騰。
前回想定した「もう一段の投げ売り」は来なかった。

### 2. ただし回復は続かなかった

10月はETFが約5.15億ドルの流出超（6月以来初の流出月）に転じ、月間 −7.3% で $77,400 引け。
11月も流出が続き（月初来 約4.4億ドル）、直近は10月高値から **−17%** の $71,300。
「底割れは回避したが、上昇も続かない」というのが2026年度ここまでの実像。

### 3. 修正その1 — 底値を引き上げ、時期を後ろ倒し

$51,000（2026年11月）→ **$60,000（2027年3月）**。6月安値 $58,500 を試す二番底を想定。
半減期18か月前ルールが示す底値ゾーン（2026年10月〜2027年1月）は現在進行中であり、まだ確定していない。

### 4. 修正その2 — 天井も小幅に引き下げ

今サイクルの最大ドローダウンは **−53.6%** で、過去サイクルの −70〜85% より明確に浅い。
これはボラティリティ圧縮の証拠であり、下値が堅いなら上値も伸びにくい。
天井を $248,000 → **$240,000** へ。**振幅が上下両方向で縮小した**というのが今回の中心的な修正。

## サイクル構造の読み方

### 1. 底値は半減期の約18か月前に来る

2028年4月の半減期から逆算すると **2026年10月〜2027年1月** が本命の底値ゾーンで、現在はその渦中。
6月の $58,500 は以後5か月間、2度の下押しに耐えた。この安値が最終的な底となる可能性は十分あるが、
10月以降の戻り高値切り下げとETF流出を踏まえ、最有力シナリオでは
**2027年1〜3月に $60,000 前後で二番底**を打つと見る。

### 2. 天井は半減期の12〜18か月後、そして年々遅くなっている

| 半減期 | ピーク | 経過月数 |
|---|---|---|
| 2012年11月 | 2013年12月 | 13か月 |
| 2016年7月 | 2017年12月 | 17か月 |
| 2020年5月 | 2021年11月 | 18か月 |
| 2024年4月 | 2025年10月 | 18か月 |

ETFと機関マネーがサイクルを平準化していることを踏まえ、2028年4月の半減期から
**20〜24か月後、すなわち2030年前半** をピーク時期と置いた。
2030年は上昇の到達点であると同時に、年後半には天井後の下落局面に入る年になる。

### 3. 倍率は逓減する

ピーク間の上昇倍率は 17倍 → 3.5倍 → 1.8倍 と縮小。最有力シナリオでは前回ピーク比
**約1.9倍** の $240,000 をサイクル天井とした。強気でも4.1倍にとどめており、
ARK Invest の2030年ベースケース $710,000 より意図的に保守的。

### 4. 半減期の効き目は今後さらに薄れる

2028年の半減でブロック報酬は 3.125 BTC → 1.5625 BTC となり、年間新規供給は
発行済総量の約0.4%まで低下する。弱気シナリオはまさに「4年サイクルが機能しなくなる」ケース。
