# チーム構成・役割分担

## 役割一覧

| 役割 | 主な業務内容 |
|---|---|
| ディレクター / チャンネル責任者 | チャンネル全体の方針決定、企画の最終承認、進行管理 |
| 企画・構成 | 動画の企画立案、構成案・台本の作成 |
| 撮影 | 機材準備、撮影の実施、素材の管理 |
| 編集 | 撮影素材の編集、テロップ・BGM・効果音の追加、書き出し |
| サムネイル・デザイン | サムネイル画像の作成、タイトル案の検討 |
| 投稿・SNS運用 | YouTubeへの投稿設定、SNSでの告知・拡散、コメント対応 |
| 分析・改善 | 視聴データの分析、次回企画への反映 |

## 役割兼任について

チーム規模に応じて、1人が複数の役割を兼任してよい。ただし各動画ごとに
「誰がどの役割を担当するか」を[企画書テンプレート](templates/video-planning-template.md)に明記する。

## 連絡・進行管理

- 進行状況は共有のタスク管理ツール(スプレッドシート等)で管理する
- 各工程の完了時は担当者が次工程の担当者へ引き継ぎを行う
- 問題や遅延が発生した場合はディレクターへ速やかに報告する
