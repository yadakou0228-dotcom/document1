# 動画制作に必要なアプリ・資機材リスト

撮影・編集・サムネイル作成・投稿管理に必要な機材とアプリをまとめる。
予算感に応じて「エントリー」「本格」の目安を併記する。

## 撮影機材

| 項目 | エントリー | 本格 | 備考 |
|---|---|---|---|
| カメラ | スマートフォン | ミラーレス一眼(Sony ZV-E10 / Canon EOS R50 等) | 三脚・スタンドとの互換性を確認 |
| マイク | スマートフォン内蔵 / クリップマイク | ピンマイク(ワイヤレス) + ガンマイク | 音声品質は視聴継続率に直結するため優先度高 |
| 照明 | デスクライト・自然光 | LEDライト(2灯以上)+ ソフトボックス | 色温度を揃えられるものを推奨 |
| 三脚・スタンド | スマホ用三脚 | 雲台付き三脚 / ジンバル | 固定撮影・手持ち撮影の両方を想定 |
| ストレージ | SDカード(128GB〜) | SDカード + 外付けSSD(バックアップ用) | 撮影素材は必ず二重に保存する |
| 背景・小道具 | 特になし | グリーンバック、収納棚等 | 企画内容に応じて用意 |

## 編集ソフト

| 用途 | 無料 | 有料 |
|---|---|---|
| 動画編集(本格) | DaVinci Resolve(無料版) | Adobe Premiere Pro / Final Cut Pro |
| 動画編集(手軽・SNS向け) | CapCut | - |
| モーショングラフィックス・エフェクト | - | Adobe After Effects |
| 音声編集・ノイズ除去 | Audacity | Adobe Audition |

## サムネイル・デザイン

| 用途 | 無料 | 有料 |
|---|---|---|
| サムネイル・バナー作成 | Canva(無料プラン) | Adobe Photoshop / Canva Pro |
| フォント・素材 | フリー素材サイト(いらすとや等) | Adobe Stock 等の有料素材サイト |

## BGM・効果音

| 用途 | 入手先 |
|---|---|
| BGM | YouTube Audio Library、DOVA-SYNDROME 等のフリー音源サイト |
| 効果音 | 効果音ラボ 等のフリー音源サイト |

著作権フリーであることを必ず確認し、利用規約(クレジット表記の要否等)に従うこと。

## 投稿・分析・運用管理

| 用途 | ツール |
|---|---|
| 投稿・分析 | YouTube Studio |
| SEO・タグ分析 | TubeBuddy / VidIQ |
| 進行管理・スケジュール共有 | スプレッドシート(Googleスプレッドシート等)、Notion |
| チーム内コミュニケーション | Slack / Chatwork / LINE WORKS 等 |

## 導入の優先順位の目安

1. マイク(音質改善が最優先)
2. 照明
3. カメラ本体のアップグレード
4. 編集ソフトの有料版移行
5. 分析・SEOツールの導入
