# noteフォロワー獲得戦略

現状(フォロワー4名・週1投稿・「フルマラソン挑戦日記」「読書感想文」の2軸)から、
収益化の前提となる**フォロワー数を増やすこと**に焦点を当てた戦略。
[note収益化戦略](note-monetization.md)のフェーズ0〜1(資産構築期)に位置づける。

## 1. 現状の診断

| 項目 | 現状 | 課題 |
|---|---|---|
| テーマ | マラソン日記/読書感想文 | どちらも投稿者が非常に多い激戦ジャンルで、**「この人をフォローする理由」が現状では弱い** |
| 頻度 | 週1回 | noteはタイムライン型のため、接触回数が少ないと新規に見つけてもらいにくい |
| プロフィール | (要確認) | 「誰が・何を・なぜ書いているか」が一目で伝わらないとフォローに繋がらない |

**結論**: 記事の質を上げる前に、(1)テーマの一貫性を作る、(2)接触回数を増やす、
(3)読者との交流を仕組み化する、の3点で「フォローする理由」を作るのが先決。

## 2. 基本方針:2つのテーマを1つの物語で束ねる

マラソンと読書は一見バラバラだが、**「安定した日常から一歩踏み出して挑戦する人の記録」**という
1本の軸で束ねると、本企画([市場分析](market-analysis.md))の強みである
**ストーリー性・当事者性**をそのまま活かせる。

- フルマラソン挑戦日記 → **「目標に向かって挑戦する過程のドキュメンタリー」**
  (レース本番日をゴールに置いたカウントダウン型連載にする。YouTube企画と同じ勝ちパターン)
- 読書感想文 → **「挑戦・人生の転機に効いた本」**に寄せる
  (単なる要約ではなく「読んで自分の行動がどう変わったか」を書く。挑戦軸と接続する)

将来的には「消防士→協力隊」の物語に合流させられる設計だが、
**在職中は所属特定リスクがあるため、職業・転身の公開時期は
[チェックリスト](checklists.md)の方針と合わせて別途判断する**(この戦略では前提にしない)。

## 3. 施策(優先順)

### ① プロフィールと固定記事を整える(最初の1週間でやる)

フォロワーが増える経路は「記事を読む → プロフィールを見る → フォロー」。入口を先に整備する。

- プロフィール文: 「何に挑戦している誰か」「フォローすると何が読めるか」を2〜3行で
- 固定記事(プロフィール記事): 自己紹介+挑戦の目標+マガジン案内を1本にまとめて固定表示
- マガジンを2つ作成: 「フルマラソン挑戦日記」「挑戦を後押しした本」
  (連載として束ねると回遊・フォローに繋がりやすい)

### ② 接触回数を増やす:週1本+短文で「週3接触」を作る

長文を増やすのではなく、**負担の小さい短い投稿で頻度を補う**。

| 種別 | 頻度 | 内容 |
|---|---|---|
| 本編記事(1,500〜3,000字) | 週1本(曜日固定) | マラソン日記 or 読書記事。交互でよい |
| 短文記事(300〜800字)/つぶやき | 週1〜2本 | 練習ログ、今週読んでいる本、気づきメモなど |

曜日と時間を固定する(例:本編=日曜夜)。noteは通勤時間帯・夜に読まれやすい。

### ③ 交流の仕組み化(フォロワー獲得の最大レバー)

フォロワーが少ない段階では、**待っていても読まれない**。自分から接点を作る。

- 1日10〜15分、同ジャンル(マラソン・ランニング・読書)の記事に**スキ+具体的なコメント**を付ける
  (「読みました」ではなく記事内容に触れた1〜2文。プロフィールへの導線になる)
- 同じ大会・同じ本について書いている人を検索して交流する(共通点があるとフォローされやすい)
- 自分の記事へのコメントには必ず返信する

### ④ noteの公式機能・企画に乗る

- **お題・コンテストに参加する**: 「#読書感想文」「#スポーツ」等の公式お題は露出が増える。
  募集中のお題は毎月確認して、合うものには必ず出す
- ハッシュタグは記事ごとに3〜5個(大きいタグ+具体タグの組み合わせ。例:#ランニング #フルマラソン #サブ4)
- 記事が公式マガジンや「注目記事」に載ると一気に伸びるため、お題参加はその抽選券と考える

### ⑤ タイトルと書き出しの型化

- タイトルに「数字・変化・感情」のどれかを入れる
  - 例:「練習ゼロから3ヶ月でハーフを完走できた理由」「30代、はじめてのフルマラソンにエントリーした」
- 書き出し3行で「誰の・何の話か」「読むと何が得られるか」を伝える(スキ・読了率に直結)
- 記事末尾に定型フッター:マガジン案内+フォロー案内+関連記事リンク

### ⑥ 週次の記録と月次の振り返り

- 週1回、`note/metrics.md`にビュー・スキ・フォロワー数を記録する
- 月1回、Claude Codeに分析を依頼し、翌月の投稿計画に反映する(下記)

## 4. Claude Codeの使い方(フォロワー獲得フェーズ)

記事・記録は`note/`ディレクトリで管理する([note収益化戦略](note-monetization.md)の構成と共通)。

| 場面 | 依頼例 |
|---|---|
| プロフィール整備 | 「この自己紹介文を、フォローする理由が伝わる3行に書き直す案を3つ出して」 |
| タイトル改善 | 「この下書きに、数字・変化・感情を入れたタイトル案を5つ。狙うハッシュタグも」 |
| 記事の型化 | 「先週のマラソン日記と同じ構成で、今週の練習メモ(箇条書き)を記事の下書きにして」 |
| 読書記事の挑戦軸への接続 | 「この感想文を『読んで行動がどう変わったか』が主役になる構成に直して」 |
| お題対応 | 「今書いている下書きを、お題『#読書の秋』の趣旨に合う形に調整して」 |
| 月次分析 | 「metrics.mdの4週分を分析して、伸びた記事の共通点と来月の投稿計画案を出して」 |

## 5. KPI(仮置き・毎月見直す)

| 時期 | フォロワー数 | 行動指標 |
|---|---|---|
| 1ヶ月後 | 15人 | プロフィール・固定記事・マガジン整備完了/週3接触の定着 |
| 3ヶ月後 | 50人 | お題参加3回以上/コメント交流を週5件ペースで継続 |
| 6ヶ月後 | 150人 | 伸びる記事の型が2つ以上確立/スキ率(スキ÷ビュー)5%以上 |

フォロワー数は運の要素(公式ピックアップ等)も大きいため、
**自分でコントロールできる行動指標(投稿数・交流数・お題参加)を優先して管理する**。

## 6. やらないこと

- フォロワー購入・相互フォロー企画への依存(収益化時に読者の質が伴わない)
- 在職中の収益化・サポート受け取り([note収益化戦略](note-monetization.md)第0章)
- 職業・所属が推測される記述(大会名・地域名の書き方は毎回チェックリストで確認)
