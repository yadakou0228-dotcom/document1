サイクル構造の読み方

1. 底値は半減期の約18か月前に来る。 過去4サイクルとも、価格の大底は半減期のおよそ1年半前に形成されてきました。 2028年4月の半減期から逆算すると 2026年10月〜2027年1月 が本命の底値ゾーンです。 2026年6月に付けた $58,000 は既に21か月ぶりの安値ですが、最有力シナリオでは もう一段の投げ売りを経て $51,000 前後で底入れすると見ています。

2. 天井は半減期の12〜18か月後、そして年々遅くなっている。 半減期からピークまでの日数は 13か月（2013年）→ 17か月（2017年）→ 18か月（2021年）→ 18か月（2025年）と 伸び続けています。ETFと機関マネーがサイクルを平準化していることを踏まえ、 2028年4月の半減期から 20〜24か月後、すなわち2030年前半 をピーク時期と置きました。 つまり2030年は「上昇の到達点」であると同時に、年後半には天井を打った後の下落局面に入る可能性が高い年です。

3. 倍率は逓減する。 ピーク間の上昇倍率は 17倍 → 3.5倍 → 1.8倍 と縮小しています。時価総額の拡大と 新規供給の相対的減少（半減期による発行減は $126,198 の時価総額に対して既に軽微）を踏まえ、 最有力シナリオでは前回ピーク比 約2.0倍 の $248,000 をサイクル天井としました。 強気シナリオでも4.3倍にとどめており、ARK Invest の2030年ベースケース $710,000 より 意図的に保守的な水準です。

4. 半減期の効き目は今後さらに薄れる。 2028年の半減でブロック報酬は 3.125 BTC → 1.5625 BTC となり、年間新規供給は 発行済総量の約0.4%まで低下します。供給ショックとしての意味は小さくなり、 弱気シナリオはまさに「4年サイクルが機能しなくなる」ケースを描いています。
