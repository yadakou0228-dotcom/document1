# 市場分析:「消防士→青年海外協力隊」チャンネル企画

企画書の内容(対象:20〜40代・転職や海外移住を考える人／内容:消防士退職から青年海外協力隊として
海外派遣されるまでの日常と現地生活／注意事項:退職日〈2026年3月31日〉までは顔出しなし)を踏まえた
市場分析。

## 1. ポジショニング:3つのジャンルの掛け合わせ

この企画は、単独では競合の多い既存ジャンルを**掛け合わせる**ことで独自性を出せる位置にある。

| ジャンル | 市場の状況 |
|---|---|
| ①公務員・消防士の転職/退職vlog | 「元消防士」を名乗るチャンネルは複数存在し、転職理由の解説やキャリア系コンテンツが中心。当事者が「退職までの過程」をリアルタイムで記録する形式は少ない |
| ②青年海外協力隊(JICA)vlog | JICA公式チャンネルはあるが広報目的。個人隊員による活動紹介動画も存在するが、登録者数の大きいチャンネルは多くなく、個人の日常密着型は手薄 |
| ③海外移住・海外生活vlog | 最も人気ジャンルの一つ。台湾・ドイツ・ベトナム・マレーシア・タイ在住者など多数の人気チャンネルが存在し、競合は激しい |

**結論**: ①×②×③の掛け合わせ(消防士という安定職を辞めてまで海外協力隊へ、という人生の転機を
時系列で追うドキュメンタリー)は直接競合が見当たらず、ニッチだが差別化しやすいポジション。

## 2. ターゲット層とニーズ

想定ターゲット(20〜40代/転職・海外移住を考えている人)が求めている情報:

- 「安定した仕事を辞める」ことへの不安・葛藤にどう向き合ったか(共感・後押し)
- 青年海外協力隊の選考・準備・生活の実態(情報が少なく需要が高い領域)
- 海外での実生活(住居・仕事・治安・文化ギャップなど)のリアルな記録

これらは「良かった探し」的な移住系コンテンツとは異なり、**キャリアの決断とその先の現実**という
ストーリー性が強く、視聴者が感情移入しやすいテーマ設計になっている。

## 3. 強み・差別化ポイント

- **当事者性**: 経験者が語る解説動画ではなく、本人が今まさに経験している過程を記録するドキュメンタリー形式
- **時系列のフック**: 「退職日(2026年3月31日)」という明確なマイルストーンがあり、そこまでの
  カウントダウン的な構成にできる(視聴継続の動機付けになる)
- **顔出しなしでも成立する題材**: 声・テロップ・活動記録中心の構成でも内容の強さで見せられる企画

## 4. リスク・課題

- **公務員としての情報発信制限**: 消防士は地方公務員であり、在職中の情報発信は所属組織の規定・
  守秘義務に抵触しないか事前確認が必須(顔出しなしの方針もこれに関連すると推測される)
- **JICA・協力隊としての規定**: 派遣後の情報発信について、JICA側のガイドライン(SNS利用規程等)の
  確認が必要
- **個人情報の特定リスク**: 顔出しなしでも、勤務先の消防署・地域・派遣国・活動内容の組み合わせから
  身元が特定される可能性がある。地名・所属の伏せ方を事前に設計する必要がある
- **投稿ペースの制約**: 海外派遣後は撮影・編集・通信環境の制約が想定されるため、無理のない更新頻度の設計が必要

## 5. 需要トレンド

- 「転職」「キャリアチェンジ」系コンテンツは継続的に需要が高いジャンル
- 「海外移住・海外生活」系は競合は多いが市場自体は大きく伸びている
- 「青年海外協力隊」は情報の絶対量が少なく、検索需要に対して供給が薄い(コンテンツギャップがある)

## 6. 推奨する打ち出し方の方向性

1. **退職までの準備期間**を「カウントダウンドキュメンタリー」として明確な区切り(週次・月次)で発信
2. 顔出しなし期間は「声・字幕・活動の記録映像」を軸にした構成で世界観を作り、
   退職後(2026年4月以降)に顔出し解禁するなら、そこを一つの話数の山場にできる
3. タイトル・サムネイルには「消防士」「青年海外協力隊」「海外移住」の3ワードをうまく組み合わせ、
   複数ジャンルの検索流入を狙う
4. コメント欄で「転職を迷っている人」との交流を意識し、共感型コミュニティを育てる
