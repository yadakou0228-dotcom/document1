# チェックリスト

## 撮影前チェックリスト

- [ ] 台本・構成案が完成している
- [ ] 撮影場所・日時が確定している
- [ ] 出演者への連絡が完了している
- [ ] 機材(カメラ・マイク・照明・バッテリー・SDカード等)の動作確認が済んでいる
- [ ] 撮影に必要な小道具・衣装が揃っている

## 編集前チェックリスト

- [ ] 撮影素材が共有ストレージにアップロードされている
- [ ] 使用するBGM・効果音の権利関係に問題がない
- [ ] 構成案・台本と撮影内容に大きな相違がない

## 公開前チェックリスト

- [ ] 動画の内容がディレクター・企画担当者の確認を通っている
- [ ] タイトル・サムネイルが決定している
- [ ] 概要欄(説明文・ハッシュタグ・リンク等)を記入している
- [ ] サムネイルの文字・画像に誤字脱字がない
- [ ] 著作権・肖像権・個人情報に関する問題がない
- [ ] 公開設定(公開日時・公開範囲・年齢制限等)が正しく設定されている
- [ ] SNS告知の準備ができている

## 公開後チェックリスト

- [ ] コメント欄を確認し、必要な返信を行った
- [ ] 初動の視聴データ(再生数・クリック率・視聴維持率)を確認した
- [ ] 問題があれば次回の企画・改善点として記録した
