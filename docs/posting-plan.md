# 初期構成・投稿プラン

企画:「消防士→青年海外協力隊」ドキュメンタリーチャンネル

- 退職日: **2027年3月31日(水)**
- 投稿開始日: **2026年12月21日(月)**(退職日の100日前)
- 投稿頻度: **週1本(毎週月曜)**
- 退職日までは顔出しなし(声・テロップ・活動記録映像を中心とした構成)

## フェーズ構成

| フェーズ | 期間 | 内容の軸 |
|---|---|---|
| フェーズ1:準備期 | 2026/12/21 〜 2027/3/31 | 退職までの葛藤・準備・カウントダウン(顔出しなし) |
| フェーズ2:出発準備期 | 2027/4/1 〜 派遣出発まで | 退職後の手続き・訓練・渡航準備(顔出し解禁を検討) |
| フェーズ3:現地派遣期 | 派遣開始後 〜 | 海外での活動・生活の記録(継続シリーズ) |

本ドキュメントではフェーズ1(初期15話)の構成を中心に扱う。フェーズ2・3は派遣スケジュール確定後に別途詳細化する。

## 運用上の注意点

- 各回のタイトル・サムネイル案は[企画書テンプレート](templates/video-planning-template.md)・[台本テンプレート](templates/script-template.md)に沿って個別に作成する
- 公開前は必ず[チェックリスト](checklists.md)で確認する(特に個人情報・所属特定リスクの項目)
- EP8(派遣国・活動内容の公開)は[市場分析](market-analysis.md)で指摘した身元特定リスクに関わるため、公開範囲・タイミングを事前にチーム内で確定させる
- 顔出し解禁(特別回)を実施するかどうかは、退職日が近づいた時点で改めて本人の意向を確認する

## フェーズ2以降について

派遣出発日・派遣国が確定次第、以下を追加で検討する。

- 出発準備〜渡航当日までのエピソード構成
- 現地派遣後の投稿頻度・撮影/通信環境を踏まえた運用体制
- 顔出し解禁後のチャンネル運営方針(コメント対応・SNS連携等)
